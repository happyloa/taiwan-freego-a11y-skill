# taiwan-freego-a11y (plugin)

A Claude Code plugin that bundles the **`taiwan-freego-a11y`** skill.

The skill makes Claude apply Taiwan《網站無障礙規範 2.0》/ WCAG 2.0 AA accessibility patterns
— the rules the government **Freego** scanner checks — whenever it writes, edits, or reviews
web UI.

See the skill itself: [`skills/taiwan-freego-a11y/SKILL.md`](skills/taiwan-freego-a11y/SKILL.md).

Install instructions are in the [repository README](../../README.md).
