# taiwan-freego-a11y（plugin）

Claude Code Plugin，內含 taiwan-freego-a11y 2.4.0 Skill：依台灣《網站無障礙規範 (115.11)》／WCAG 2.2 開發、修正與稽核網站，預設 AA。

```text
/plugin install taiwan-freego-a11y --marketplace happyloa/taiwan-freego-a11y-skill
```

涵蓋 86 項有效成功準則、28 個 C 碼、216 個 E 碼；AA 累計為 55 項準則、23 個 C 碼、161 個 E 碼。115.11 認證自 2026-11-30 開始，同日起不再受理 110.07 申請。未執行的檢查標示 Pending，不能當成網站已通過認證。

## English

Bundles the taiwan-freego-a11y 2.4.0 skill for Taiwan 115.11 / WCAG 2.2, AA by default: the full A/AA/AAA inventory, implementation guidance, and an evidence-based manual audit workflow. 115.11 certification starts on 2026-11-30. Inventory coverage does not mean every check runs automatically or that a site is certified.
